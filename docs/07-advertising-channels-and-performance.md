# 07｜六家求职平台广告投放、渠道分配与转化证据

> **核查基准日：2026-10-21（新加坡时间）**  
> 研究对象：JobStreet by SEEK、MyCareersFuture（MCF/WSG）、Indeed、LinkedIn、FastJobs、foundit。  
> **先读结论：**公开资料足以识别各家可用/公开采用的渠道、广告产品形式和少量活动效果；无法还原六家在新加坡的广告预算占比、媒体计划总量、完整CPC/CPA、求职者申请至录用归因。本页不把“可投放的广告产品”写成“品牌一定在投”，也不把招聘客户的职位广告结果说成平台自己的用户获客结果。

## 1. 核心结论

1. **没有公开的六平台新加坡预算分配表。**没有找到可比的 paid search / paid social / display / influencer / OOH / event 预算比例，也没有统一的媒体花费或有效求职者获取成本。估算网站访问的 Direct、Organic Search、Paid Search、Social、Referral 分布，是渠道访问份额估算，不是广告预算份额，也不证明付费带来申请。
2. **有具体可量化的新加坡 campaign：**WSG曾通过Carousell原生职位列表样式推广就业项目。代理商案例称5周内达成KPI，实际申请比预期多近10%、CTR比Carousell平均高1%、获得1,400万曝光。代理商没有公开预算、实际申请绝对数、后续就业人数或实验设计；这是供应商自报 campaign 案例，不是独立审计。[Wild案例：Workforce Singapore](https://www.wild.sg/case-studies/workforce-singapore)
3. **JobStreet/SEEK的区域买量渠道有公开案例，但新加坡结果不能拆分。**代理商称为SEEK/JobStreet在新加坡和菲律宾、JobsDB在泰国管理四年付费媒体，渠道包括Paid Search、Paid Social、Influencer和Earned Media；案例页所列应用注册/申请提升主要来自印尼“Next Million Jobs”区域活动，不能移植为新加坡效果。[M+C Saatchi Performance案例](https://www.mcsaatchiperformance.com/case-studies/how-jobstreet-by-seek-rebalanced-media-spend-to-activate-untapped-regions/)
4. **招聘平台的站内职位广告表现不等于品牌获客。**Indeed称Sponsored Jobs可获得免费职位广告最多4.5倍点击；这是Indeed对雇主广告产品的比较性营销宣称，不等于多4.5倍申请或录用。[Indeed Singapore雇主FAQ](https://sg.indeed.com/hire/faq)。SEEK称新加坡每广告申请数同比增加146%，且推出免费基础广告+按效果购买的高级曝光；这是平台公布的招聘供需/产品使用信息，并非它自己的用户广告渠道转化率。[JobStreet新模式公告](https://sg.jobstreet.com/about/news/article/reimagines-business-model-singapore)
5. **各平台的转化终点不同。**一次曝光→点击→落地页→注册→求职搜索→申请开始→完整申请→合格申请→面试→录用是一条漏斗。不同平台/案例可能只报其中一步；“申请开始”甚至可能只是点击/打开申请，不代表完成、合格或录用。

## 3. 渠道分布：目前能说什么

### 3.1 品牌自己的获客渠道（求职者端）

| 渠道 | 已确认的用法/案例 | 公开分配份额 |
|---|---|---|
| 搜索（SEO与付费搜索） | JobStreet/SEEK区域付费案例明确含Paid Search；六家均有职位/职业内容带来自然搜索的可能，但“有SEO页面”不是Paid Search证据。 | 未找到各平台新加坡预算、点击或访问占比。网站流量工具估算的Paid Search份额应单列为流量来源估算，不能转成spend share。 |
| 社交广告（Meta/LinkedIn等） | SEEK案例含Paid Social；JobStreet Singapore有本地campaign报道；其他平台可能使用自有社媒，但没有同一时间窗广告逐条证据。 | 未找到六平台一致的Meta/LinkedIn/TikTok投放量与费用。Meta Ad Library普通广告查询本次浏览器落入政治/社会议题分类，未完成普通广告的有效全量搜索，故登记为**访问/筛选受限**，不是“没有广告”。 |
| 展示/程序化/第三方流量 | SEEK区域campaign材料提及display；Indeed条款明确Sponsored Jobs可在站外进行自动化投放；广告产品功能说明不代表品牌自身display投放。 | 不公开。跨站曝光和平台内推荐也不宜在广告库里简单比数。 |
| 影响者、内容合作、PR/Earned | SEEK/JobStreet代理案例明列Influencer和Earned Media；招聘会与社媒内容能形成活动传播。 | 未找到可核验的完整创作者名单、SG付费标记、单条价格和归因。 |
| OOH/广播/活动 | JobStreet Singapore有交通媒体与招聘会证据；WSG/MCF生态有Carousell案例、公共路演；FastJobs通过招聘活动和实体雇主物料触达。 | 无统一预算、触达去重或后续注册/申请增量。活动访客不等于网站流量或用户。 |
| App安装/CRM/推送 | FastJobs自有App/Push/SMS/EDM库存明显；其他竞品也有App、邮件/通知触点，但不据此认定付费安装投放。 | 新加坡品牌投放的安装量、激活成本、留存、推送退订及再营销花费未公开。 |

**流量来源的现有代理数据：**README与[02流量/SEO附录](02-traffic-seo-ads.md)已有Semrush的国家/月度访问估算，但月份/域名/设备范围还未完全一致。它只能作为总访问及第三方流量渠道比例的方向性估计，不能回答预算如何分配。若要决定地区预算，必须先取得同一工具、同一月份、同一国家、同一设备口径的渠道趋势表。

### 3.2 招聘客户买的“职位广告”渠道

这属于平台的广告库存/商业模式，而非品牌消费者营销：

- JobStreet按Lite/Basic/Advanced/Premium等招聘广告层级提供搜索与推荐曝光、定向、邀请候选人、AI筛选等；价格因市场、职位与产品组合可能动态或需询价。[SEEK Job Ads SG](https://sg.employer.seek.com/products/jobads)
- Indeed收费可基于展示、点击、Started Application、招聘会Started RSVP/RSVP等；具体定义和收取时点以合同与新加坡条款为准。Started Application不保证候选人提交完整申请。[Indeed广告条款](https://sg.indeed.com/legal?hl=en_SG)
- FastJobs用FastCoins购买职位刊登时长/置顶Bump，并提供Splash、Push、Banner、SMS/EDM、线下触点等自有媒体组合；具体包价需联系销售。[FastJobs雇主页](https://employer.fastjobs.sg/)
- LinkedIn的招聘者工具、职位发布和广告Campaign Manager是不同预算项；公开市场页没有本次可比的六平台SG完整价目表。
- MCF是政府服务平台，不适用商业招聘网站同类“雇主买排名广告”的完全相同经济模型。其职位列表/求职服务与政府项目宣传需分开。

## 4. 转化与效果：公开结果的证据强度

| 指标/案例 | 可公开说的内容 | 不能据此推论 |

| WSG×Carousell原生广告 | 代理商披露14M impressions、CTR比平台均值高1%、实际申请目标超预期近10%、5周 | 不知道预算、点击绝对值、实际申请数、去重求职者、有效申请、录用、增量对照组；不能算CPA或ROI |

| Indeed Sponsored Job最多4.5×点击 | Indeed雇主产品FAQ中的宣传性比较指标，free listing为比较对象 | 不是付费广告的4.5×完整申请、合格申请或录用；不能推导消费者广告CAC |

| 社媒点赞/粉丝、招聘会访客 | 公开可见的互动/参与量或组织方自报 | 不等于广告曝光、有效到访、注册、完成申请或录用 |

## 5. 新加坡广告资料库核验日志（本轮）

### Meta Ad Library

- 新加坡地区查询入口可打开，但当前交互状态落在“社会议题、选举或政治”广告类别，并返回与求职平台无关的关键词噪声。因未能在本轮把广告类别切换到“All ads”并稳定核对广告主页面，六平台均记为**普通商业广告：访问/筛选受限，未完成核验**。
- 不把该页政治广告结果计入JobStreet等品牌，不将其当作零广告。
- Meta说明普通商业广告库用于查看当前投放广告；Meta Ad Library API对全球一般商业广告可检索范围受限，API公开主要涵盖全球政治/社会议题广告、过去一年EU/UK各类广告。[Meta Ad Library API说明](https://www.facebook.com/ads/library/api/) · [Meta Ad Library](https://www.facebook.com/ads/library/)

### Google Ads Transparency Center 与其他广告库

- Google Ads Transparency Center提供广告主及广告素材透明度搜索，但本轮网页读取工具不能加载其动态结果；故六平台Google广告记录为**未完成逐条核验/访问受限**，不写“未投放”。[Google Ads Transparency Center](https://adstransparency.google.com/)
- TikTok Commercial Content Library/广告资料库页面可打开但未提供可读的检索结果；LinkedIn广告库也没有公开完整的品牌投放历史和预算。若需要逐条核验，应记录页面截图、广告主法定名、国家、日期、素材与落地页。
- 公开商业广告库通常不披露精确预算/转化。Meta政治广告预算透明度规则不能外推到普通招聘品牌广告。

## 6. 地区投放决策：可用证据与建议

### 6.1 现在可以用于地区优先级的硬证据

- 新加坡本地平台需求/流量、职位结构与求职者状态基线见本仓库[01市场与求职人群](01-market-and-jobseekers.md)和[02流量/SEO附录](02-traffic-seo-ads.md)。
- 求职渠道层面，MOM与Randstad数据显示求职网站、线上职位广告、LinkedIn/专业社交网络、朋友推荐、公共就业服务等路径并行；渠道偏好随PMET/非PMET及年龄、学历而异。不得将“流量大”直接解释为“应该把广告预算全投那里”。
- JobStreet的SG OOH和JobStreet Career Fair、FastJobs/e2i线下面试活动、WSG的Carousell案例证明本地线上线下渠道可被用于求职者触达；公开数值不足以判断这些渠道的成本效率。
- 目前没有可比较的竞品媒体份额数据，所以任何“竞品把X%预算投新加坡/某平台”的表述都不应出现在投资决策中。

### 6.2 建议的下一步实测（用于选市场，不是冒充竞品内部数据）

如果你准备做自己的地区测试，建议以**市场×渠道×受众**做小额、分层、可停损实验，并提前设定同一口径：

1. 先按地区衡量可服务求职人群、职位密度、雇主获客成本和本地工作许可/可服务对象，地区总量不作为单一决策依据。
2. 至少拆成PMET与非PMET、应届/早期职业与经验求职者、求职者与雇主两侧；将搜索意图词与受众定向分开。
3. 渠道组合可先测试Google Search（高意向）、Meta/TikTok（需求唤起/应用安装）、LinkedIn（专业岗位）、本地求职社群/合作伙伴和线下招聘活动；这些是**实验候选渠道**，不代表竞品已在所有市场采用。
4. 每个地区单独埋UTM、应用商店来源、落地页和转化事件；在隐私与平台政策允许范围内记录曝光、点击、落地页到达、注册、资料完整、职位浏览、申请开始、完成申请、合格申请、面试、录用。
5. 至少保留对照组/地域留白或前后对比，避免把季节性招聘和职位供给变化误判为广告效果。报告边际成本：每个有效注册、完成申请、合格申请、面试和录用成本。
6. 将预算、媒体费、代理服务费、创作者制作费、活动成本分别列项；不要用“曝光单价”取代招聘质量或获聘成本。

**地区排名的决策门槛：**只有在同一受众定义、同一观察期、同一转化事件、同一追踪完整度下比较每地区的有效申请和面试/录用成本，才能决定扩量。竞品第三方流量、广告库素材数、粉丝数、宏观人口数只能作为先验线索。

| Creative | 原文案、图/视频、语言、招聘人群/雇主受众、素材存档链接 |
| CTA / Landing page | Apply/Download/Register/Explore等、完整落地URL、是否重定向 |
| Spend / Delivery | 金额/区间、impressions/reach/click；不可见写“平台未公开” |
| Conversion | 注册、申请开始、完整申请、合格申请、面试、录用；说明归因窗口/去重 |
| Source status | 已核实、待复核、访问受限、指定库未检出、未找到、需后台数据 |
| Evidence class | 官方、平台自报、代理商案例、广告库直接观测、第三方估算、研究者观察 |
