# 06｜核心指标追踪与本轮补查

> **快照日期：2026-10-21（新加坡时间）**  
> 本页把后续研究要求转成可重复更新的指标台账，并记录本轮能由公开来源确认的最新数据。来源等级：政府统计/官方调查、平台自报、第三方估算、研究者观察。不能公开核验的数字标为“未找到/访问受限”，不以零代替。

## 1. 市场与求职者基准

### 1.1 毕业人数、调查时点与毕业后状态

### 1.3 MOM劳动力与需求基准（2025）

- **劳动力与失业：**MOM《Labour Force in Singapore 2025》以居民（公民+PR）为主要调查人口；2025年居民劳动力参与率为67.9%。PMET居民失业率2.8%，非PMET为2.8%；长期失业率分别为0.6%与0.5%。这些是居民劳动力背景，不代表平台用户偏好或所有外籍就业者。[MOM Labour Force 2025](https://stats.mom.gov.sg/Pages/Labour-Force-In-Singapore-2025.aspx?PageVersion=1024) · [Advance release](https://www.mom.gov.sg/newsroom/press-releases/2025/1128-labour-force-in-singapore-advance-release-2025)
- **职业代理分类：**就业居民中PMET 64.2%、文职/销售/服务（CSSW）18.9%、生产/运输操作/清洁/劳工（PTOCL）17.0%。做“白领/蓝领”产品讨论时，建议明确写“PMET作为白领近似代理；PTOCL作为操作型/蓝领近似代理；CSSW单独列示”，并指出两者都不是严格定义。不得把CSSW硬并入任何一侧。
- **职位空缺：**2025年年度平均空缺75,900（2024年75,400）；2025年12月每名求职者对应1.58个职位空缺，空缺率3.1%。2025年9月职位空缺调查中49.3%为新设职位；雇主对79.6%的空缺表示学历不是招聘的主要决定因素；长期空缺（至少6个月）占比17.1%。[MOM Job Vacancies 2025](https://stats.mom.gov.sg/Pages/Job-Vacancies-2025.aspx?PageVersion=512) · [MOM新闻稿](https://www.mom.gov.sg/newsroom/press-releases/2026/0320-job-vacancies-report-2025)
- **毕业生适合的入门级PMET空缺：**2025年12月32,500个（2024年12月34,600）。定义为薪资范围2,300至5,000新元、在招聘网站刊登并适合新毕业生及本地求职者的PMET职位；这是MOM定义的职位空缺指标，不是某一个平台的挂牌数或录用数。[MOM Job Vacancies 2025新闻稿注释](https://www.mom.gov.sg/newsroom/press-releases/2026/0320-job-vacancies-report-2025)
- **分解数据：**MOM月度/季度劳动力报告提供年龄、行业、最高学历、职业组等失业率、裁员率及空缺表。必须记录具体月份/季度，季节调整状态，居民/公民范围和分母；月度经季调总体失业率不可与6月PMET分组率混用。[MOM Labour Market Reports](https://stats.mom.gov.sg/Pages/Labour-Market-Report.aspx) · [MOM Job Vacancy dashboard](https://stats.mom.gov.sg/report/MOM-IMAS-JBY/Main.html)

## 2. 平台与获客：本轮核验边界

### 2.1 同月同国家网站流量

已有附录中Semrush可见值不是完整的同月六平台面板：JobStreet、Indeed、FastJobs、foundit为2026-09新加坡估算；MCF详细值为2026-08；LinkedIn约844万是LinkedIn全站、不是Jobs模块。因此本轮结论是：**尚未形成可严格横向比较的“同月、同国、同设备、同域名范围”六平台样本**。不应把两个不同月份的MCF流量与9月值画成同月排名。查看[02流量与SEO附录](02-traffic-seo-ads.md)及[Semrush Singapore HR分类页](https://www.semrush.com/trending-websites/sg/human-resources)。

下一次截面要固定同一月份，并记录：
1. 域名（含/不含子域）、国家、自然月、桌面/移动Web；
2. visits、unique visitors（若有）、直接/搜索/社交/推荐/展示广告渠道；
3. 自然和付费搜索词分别记录词、国家、位置/设备、流量估值与抓取日期；
4. LinkedIn总体与LinkedIn Jobs产品流量分开；Web访问绝不等同App月活；
5. 提供商缺值应记录为“无数据/套餐限制”，不能填0。

### 2.2 广告库逐条核验

本轮既有广告章节包括SEEK/JobStreet区域与本地广告证据、部分招聘产品广告形式及公开案例，但**不构成六品牌全渠道广告库的完整逐条审计**。平台或广告库登录墙、地区筛选器错误、动态素材无法访问，都要记“访问受限”；只有执行了广告主、国家和日期筛选且没有结果，才记“在该库该次查询未检出”。

单条记录字段：平台/广告库、广告主法定名与页面名、国家/地区、素材ID或存档链接、首次/最后展示日期、素材文案/媒体形式、CTA、落地页、查询日期、访问状态、截图/存档。Meta Ad Library、Google Ads Transparency Center、LinkedIn广告资料库各自覆盖不同广告库存；一个库未检出不能说明该品牌没有付费广告。预算/曝光只在工具明确公开时记录，不能根据广告数量估预算。

### 2.3 社媒、App、职位供给、价格及活动数据

- **社媒30条样本：**现有[03社媒附录](03-social-operations.md)是可见内容样本和账号归属核查，但不同账号的可见条数、页面登录态和本地性不同，不能称六品牌均已完成连续30条且同一观察窗的审计。后续每条记录日期、平台、账号、本地/全球、格式、主题、CTA、互动数、出站链接和抓取时间。隐藏互动记“页面未显示”；粉丝/赞/评论不能代表曝光与转化。
- **App商店：**本轮文档未建立六品牌App在新加坡区商店的同日排名、评分分布、评论样本和版本更新面板。之后应按新加坡Apple App Store及Google Play分别记录应用包名/开发者、地区、名次类别与榜单、评分/评论数、版本号、最近更新日、评论抽样日期。商店榜单缺席不等于没有App；Web/App指标分开。
- **职位供给：**本轮没有构建六个平台同日、按职位ID去重的职位快照。新增采样时固定搜索词/职业分类/地点/日期，保存职位URL与雇主、标题、薪资、全职/兼职、经验要求、发布日期；去重规则至少使用平台职位ID/规范URL，再辅以雇主+标准化标题+地点。聚合网站重复抓取、同一广告多地点和重复刊登要单独标记。广告数不是独立岗位数，更不是招聘人数或录用。
- **招聘者收费：**JobStreet、Indeed、LinkedIn、FastJobs、foundit的雇主产品/套餐价格可能按国家、客户、合同和产品而异；未找到可比、公开、可直接下单的完整新加坡价目表时，应登记“需销售报价/未公开”，保留套餐功能、计价单位、日期和来源，不估算ARPA。
- **线下活动：**既有[04线下附录](04-local-campaigns.md)记录可核案例及主办身份。对人数、职位、面试、到场、录用分别记活动届次、时间地点、主办/赞助身份、指标定义、披露方和审计状态。FastJobs公布的面试次数、JobStreet的登记/到访数、公共路演访客数单位不同，不可相加或算平台份额。

## 3. 数据台账模板

建议每次更新将快照追加到独立CSV/表格，不覆盖旧数：

| 字段 | 说明 |
|---|---|
| indicator_id / 指标名 | 固定指标标识，避免更名造成断档 |
| entity / platform | 国家、平台或群体 |
| value / unit | 原始数值和单位，不先换算 |
| numerator / denominator | 比例的分子、分母；不适用写N/A |
| period_start / period_end | 统计期或调查期 |
| population / geography | 人群定义与地区 |
| source_type | 官方统计、平台自报、第三方估算、研究者观察 |
| sample_n / method | 样本量、抽样/估算方法、加权与去重 |
| captured_at | 抓取日期与时区 |
| source_url / evidence | URL、广告ID、截图/存档文件 |
| status | 已核实、待复核、访问受限、未检出、未找到、需后台数据 |
| caveat | 口径限制与不可推断事项 |

状态定义：
- **已核实：**来源内容与指标口径可直接对应，链接/文件可回查。
- **待复核：**有公开线索，但时间、归属、样本或口径未完全确认。
- **访问受限：**已尝试对应公开入口，但登录、地区、机器人拦截或页面渲染限制阻止核验。
- **未检出：**在指定数据库/账号、地区、日期范围内完成查询，未返回匹配记录。
- **未找到：**本轮公开检索未确认；不能解释为不存在。
- **需后台数据：**曝光、预算、申请、独立用户、录用归因等一般不公开的指标。

## 4. 结论与使用边界

- MOM统计描述劳动力供给背景，不直接说明哪个平台被谁偏好；GES就业率必须同时报告调查日和劳动力分母。
- MCF的官方触达/就业数据可作为公共服务平台锚点，不能把后续就业归因给MCF一个渠道。
- FastJobs用户比例来自平台自报，其他五个平台缺少可比的公开新加坡人群细分。
- Semrush/Similarweb访问估算、社媒关注数、App评论、职位广告数、活动到访/面试数是不同单位、不同覆盖范围，不能合成市场份额或获客ROI。
- 公开广告库未检出、社媒未显示互动或活动没有报道，都只描述本次检索结果。真实曝光、预算、求职者去重、申请转化和录用归因通常需要平台或雇主后台。
